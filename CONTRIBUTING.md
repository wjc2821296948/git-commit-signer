# Contributing

Thanks for considering a contribution.

## Before opening a pull request

1. Keep V0.1 read-only. Do not add commit rewriting or push behavior to the discovery release.
2. Do not add code that prints, exports, or transmits GitHub tokens or private SSH keys.
3. Preserve Windows PowerShell 5.1 compatibility unless a change is explicitly documented as requiring PowerShell 7+.
4. Document every GitHub API endpoint and whether it is read-only or mutating.
5. Include manual test steps and expected output for Windows.

## Pull requests

Please keep changes focused, explain the motivation, list tested PowerShell versions, and include sample output with private repository names and other sensitive information redacted.
